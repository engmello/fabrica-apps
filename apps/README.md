# Apps

Cada app do processo tem uma pasta aqui, `<sigla>-app/`, criada pelo comando `/novo-app`.
Os documentos ficam em `<sigla>-app/docs/` e o andamento em `<sigla>-app/docs/registro.md`.

A partir da etapa E3.1 o app ganha um repositório próprio no GitHub e a pasta aqui guarda só um
`README.md` com o link para ele.
